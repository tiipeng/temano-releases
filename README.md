# Temano für Mac

Downloads der signierten und von Apple notarisierten Mac-App von Temano. Der Quellcode liegt nicht hier.

https://temano.tipengstudio.com

## Claude Code plugin

When Claude Code gets stuck at a passkey, password prompt, CAPTCHA or confirmation on your Mac, it sends you a private link to finish the step on your iPhone.

```
/plugin marketplace add tiipeng/temano-releases
/plugin install temano@temano
```
